## About

I build practical cybersecurity tooling, software, and technical documentation across Linux, Android, iOS, networking, automation, OSINT, and security research.

My work focuses on reproducible engineering: building the lab, solving the problem, testing the result, and documenting enough detail for someone else to reproduce it.

## Featured Projects

### [CyberDatabase](https://github.com/m4ckDev/CyberDatabase)

Central cybersecurity knowledge base for labs, tooling, OSINT, threat intelligence, hardware references, automation, research, and reproducible technical documentation.
